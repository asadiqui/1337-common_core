# 42 Piscine / Pool

## 🗣️ About The Project
The 42 Piscine is an intensive 4-week programming bootcamp focusing on the C language. It is designed to test logic, endurance, and adaptability in a peer-to-peer learning environment without teachers or traditional classes.

### Subjects Covered
- **C Programming Basics**: Syntax, variables, loops, conditional statements.
- **Memory Management**: Pointers, arrays, dynamic memory allocation (`malloc`, `free`).
- **String Manipulation**: Recreating basic `string.h` functions from scratch.
- **Algorithmics**: Sorting arrays, traversing data structures, basic math logic functions.
- **Shell Scripting**: Basic UNIX commands, permissions, Git version control.

## 🛠️ Skills Acquired
- Resilience and problem-solving
- Autonomy in learning new concepts
- Peer-to-peer evaluation and collaboration
- Low-level programming concepts
- Strict adherence to coding norms (The Norme)
